# Changelog

## [Unreleased]

## [1.0.1] - 2026-08-30

- Use a bright light-only interface with improved mobile navigation,
  accessibility state, and workflow-order feedback.
- Centralize workbench version metadata and reject mismatched release tags.
- Bound local release rollback archives and prune stale development leases.
- Minimize health-check path disclosure and fail closed on unhandled server
  rejections.
- Expand browser interaction coverage, Git-history auditing, CodeQL, and
  pinned Node 24 GitHub Actions.

## [1.0.0] - 2026-08-29

- First public release line.
- Local workflow orchestration with approval-gated execution.
- Versioned SQLite-backed control state with legacy JSON migration.
- Cross-platform supervisor, installer, backup, restore, and portable release
  verification.
- English-first interface with a switchable Chinese locale.
