# Security Policy

## Supported versions

Security fixes are currently provided for the latest `main` release and the
latest tagged release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use a private
GitHub security advisory for this repository, or contact the repository owner
through the private contact method listed on the repository profile. Include
the affected version, operating system, reproduction steps, and a minimal
proof of concept. Do not include credentials, tokens, private project files,
or complete Codex transcripts.

The workbench is designed for one local user and binds to loopback. That is a
boundary, not a substitute for operating-system permissions or sandboxing.
